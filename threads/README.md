# Saved threads

Exported Meristem threads. Load one with **Import** on the paste screen —
paste the file's contents into the box and the whole page tree is restored,
notes and anchors included.

The export format is what `exportTree()` produces: a flat `nodes` array where
each node carries its own `parents`, its `text`, the `quote`/`note` that
provoked it, and the `s`/`e`/`para` token span anchoring it in its first
parent. Child links are rebuilt from `parents` on import, so the two can't
disagree.
